## Решение 2. Instance Group и Network Load Balancer

Инфраструктура развёрнута в Yandex Cloud средствами Terraform:

- Созданы сеть `netology-lb-network` и подсеть `netology-lb-subnet` (`10.10.0.0/24`, зона `ru-central1-d`).
- Настроена группа безопасности с доступом к веб-серверам по TCP/80.
- Создана группа виртуальных машин `netology-lb-ig` с фиксированным размером **3 экземпляра** на базе LAMP-образа.
- Через `cloud-init` на веб-серверах настроена стартовая страница с изображением из Object Storage.
- Создан сетевой балансировщик `netology-lb` с TCP-обработчиком на порту 80 и целевой группой `netology-lb-target-group`.
- Настроены проверки состояния HTTP-сервиса. Все три цели балансировщика получили статус `HEALTHY`.
